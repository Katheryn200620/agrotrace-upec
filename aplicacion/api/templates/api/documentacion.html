Obtener un token

curl -X POST http://127.0.0.1:8000/api/v1/token/ \
  -d "username=comercial" -d "password=upec2026"

Respuesta: {"token": "9f1c…"}. Luego envíe la cabecera:

Authorization: Token 9f1c…

Reglas

  • Cada usuario ve y modifica solo lo que su área le permite (403 si no).
  • Las altas se validan con los mismos formularios de la web (400 con el detalle del error).
  • Los eventos de trazabilidad y la auditoría no se modifican.
  • Filtros: ?q=texto, ?estado=…, paginación ?page=2&tamano=50.
  • La documentación completa está en Documentacion_API.md.
