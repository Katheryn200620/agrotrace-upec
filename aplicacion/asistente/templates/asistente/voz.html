Compatibilidad y permisos

  • Funciona en Google Chrome y Microsoft Edge (computador y Android). Firefox no tiene reconocimiento de voz.
  • El navegador pide permiso para usar el micrófono la primera vez: elija «Permitir».
  • Requiere http://127.0.0.1, localhost o una dirección https. Desde otra IP sin https el navegador bloquea el micrófono.
  • El reconocimiento lo hace el servicio del navegador y necesita internet.
  • Siempre puede usar el menú y el teclado: la voz es una alternativa.
